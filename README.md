# dosya-cebi
Android file manager for RAR, ZIP, 7z and PDF files — built with Kotlin 
İlk sürüm.

ÖZELLİKLER
- RAR, RAR5, ZIP, 7z, arşivlerini açma
- Arşiv içeriğini çıkarmadan önizleme
- Tümünü klasöre çıkarma
- PDF görüntüleme
- Koyu tema
- Türkçe, İngilizce, Arapça, Korece, Çince

KURULUM
1. Aşağıdan APK'yı indirin
2. Dosyaya dokunun
3. "Bilinmeyen kaynaklara izin ver" çıkarsa izin verin
4. Uygulama açılınca TÜM DOSYA ERİŞİMİ izni verin
   Bu izin verilmezse dosya listesi boş kalır.

GEREKSİNİM
Android 7.0 veya üzeri

Geri bildirim için Issues bölümünü kullanabilirsiniz.
